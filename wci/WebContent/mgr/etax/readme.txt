MP세금계산서 (T_BILL_TB, T_BILL_ITEM_TB, T_BILL_STATUS_HISTORY_TB)
---------------------------------------------------------------------------------------------
가. 작성

자동 및 수기발행 등 모든 세금계산서는 발행신청상태로 작성됨 > 발행신청관리 페이지에서 확인
정상 결제전문이 들어오면 발행신청상태로 세금계산서 자동 작성 (kr.co.soap.kodit.loan.emtnet.EmtNetK311 참고)
월합세금계산서를 신청한 경우에는 자동작성되지 않음 > 관리자의 월합세금계산서관리에서 발행
월합세금계산서에서의 발행도 발행신청상태가 됨

나. 발행

발행신청관리 페이지에서 세금계산서를 최종확인 한 후 발행을 선택하면 선택한 세금계산서가 일괄 전송됨(TaxPublishProc.jsp 참고). 
이때 카카오톡으로 MP수수료부담처와 판매사에 메시지가 발송됨
  - TaxPublishProc.jsp 참고
  - 결제통보시 발송되는 것이 아님 주의
  - 매매계약서가 있는 경우에만 발송
발행하면 바로빌로 전송되며, 바로빌에서 국세청으로 전송함 < 5분마다 바로빌에서 상태값을 수신(BillStatusReceiver.sh)하여 변경함
데이터베이스 상에서의 상태값(T_BILL_TB.BILL_STATUS)은
            1   // 국세청전송전(MP에서 바로빌로 전송한 상태)
            2, 3  // 국세청전송중
            4   // [완료]국세청 전송성공
            5   // [완료]국세청 전송실패
상태값이 마이너스면 https://dev.barobill.co.kr/docs/references/%EB%B0%94%EB%A1%9C%EB%B9%8C-API-%EC%98%A4%EB%A5%98%EC%BD%94%EB%93%9C에서 오류코드로 조회해 볼 것

다. 참고

만약 발행되지 않았다면, 관리자 매매계약서 상세 페이지에서 발행할 수 있음
테스트환경에서는 발행하고 국세청전송 상태로 보여도 실제 국세청에 전송하지는 않음
관리자>정산관리>세금계산서관리의 우측상단의 연동관리를 선택하면 바로빌로 바로 접속할 수 있음. 특히 인증서관리에 유의할 것
configuration.properties에 관련된 설정이 있음 (운영환경으로 변경하려면, ETAX_RELEASE_YN, ETAX_KEY 등의 변경 필요)
